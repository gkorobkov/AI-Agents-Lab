# Учебная библиотека MCP

Откройте `index.html?page=mcp`. Встроенный пример «Учебный помощник» содержит `greet_student`: принимает имя и возвращает приветствие. Сайт остаётся браузерным приложением без npm-зависимостей.

## Путь студента

1. Нажмите **Проверить MCP**. Клиент выполнит `initialize`, `notifications/initialized`, `tools/list`.
2. Введите `{"name":"Анна"}` и нажмите **Вызвать инструмент**. Раскройте «Обмен MCP», чтобы посмотреть JSON-RPC.
3. Нажмите **Собрать свой MCP**. Измените название, добавьте инструменты и аргументы, задайте JSON-шаблоны ответов. `{{name}}` подставляет аргумент; `{{location.city}}` читает вложенное поле. Полная подстановка сохраняет тип значения.
4. Добавьте готовый HTTP-инструмент из библиотеки Tools. Его настройки копируются в MCP. Для изменения запроса отредактируйте инструмент в Tools и добавьте его заново.
5. **Сохранить MCP** сохраняет определение локально. **Подключить к агенту** добавляет инструменты в настройки OpenAI API. Модель получает определения функций; вызов выполняется по кнопке **Выполнить MCP-вызов**. Полученный результат отправляется модели существующей кнопкой продолжения.

Учебный стенд передаёт JSON-RPC внутри браузера, а не по сети. Шаблоны не обращаются к ИИ и не генерируют новые знания. HTTP-инструменты делают реальные запросы. Текст интерфейса различает этот режим и настоящее удалённое подключение.

## Настоящий сервер

**Скачать server.mjs** создаёт исполняемый сервер из текущего конструктора. В отдельной папке с файлом:

```sh
npm install @modelcontextprotocol/sdk@1.30.0
node server.mjs
```

Требуется Node.js 20+. Адрес по умолчанию: `http://127.0.0.1:3100/mcp`. Сервер работает на официальном SDK; исходный runtime обработчиков общий с браузерным стендом. Он поддерживает Streamable HTTP без серверной сессии и JSON-ответы. `node server.mjs --stdio` запускает stdio для внешнего MCP-клиента.

В библиотеке выберите **Подключить сервер**, введите адрес и нажмите **Проверить MCP**. Браузер может запросить доступ к локальной сети. Если политика браузера запрещает доступ к localhost с размещённого сайта, откройте лабораторию локально через `ui-start.cmd` и экспортируйте сервер оттуда.

Переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт HTTP-сервера, по умолчанию 3100 |
| `MCP_ALLOWED_ORIGINS` | Дополнительные разрешённые origin через запятую; текущий адрес лаборатории включён при экспорте |
| `MCP_TOKEN` | Необязательный Bearer-токен для доступа к HTTP MCP |
| `MCP_TOOL_KEY_1`, `MCP_TOOL_KEY_2`, … | Ключи HTTP-инструментов по номеру инструмента в списке |

Сервер слушает только `127.0.0.1`, проверяет Host и Origin и не следует HTTP-редиректам инструментов. Публикация на внешнем сервере не выполняется конструктором.

## Удалённые MCP

Клиент поддерживает Streamable HTTP с ответами JSON или SSE, версию `2025-11-25` и согласование `2025-06-18` / `2025-03-26`, заголовки сессии и постраничный `tools/list`. Сервер должен разрешать CORS для origin лаборатории и заголовков `Content-Type`, `Authorization`, `MCP-Protocol-Version`, `Mcp-Session-Id`; `Mcp-Session-Id` нужно добавить в `Access-Control-Expose-Headers`.

Поддерживаются инструменты и необязательный Bearer-токен. OAuth, старый HTTP+SSE, resources, prompts, sampling, elicitation и фоновые уведомления сервера не реализованы. Потерянный поток не возобновляется автоматически. Истёкшая сессия требует новой проверки; `tools/call` автоматически не повторяется, чтобы не дублировать действие. Тайм-аут одного запроса — 30 секунд.

## Данные и ограничения

- Определения хранятся в `ai_mcp_library_v1`, токены — в `sessionStorage` под `ai_mcp_secret:<id>` с привязкой к origin. Токены не попадают в определения, экспорт или функции, отправляемые модели.
- Агент получает отдельный снимок MCP. Изменение библиотеки не меняет уже подключённую копию; для обновления удалите её из настроек и подключите снова.
- Экспорт JSON переносит определение. Импорт создаёт новый черновик, не перезаписывая существующие записи; нажмите «Сохранить MCP».
- Лимиты: 100 сохранённых серверов, 30 инструментов в конструкторе, 2 МБ импортируемого JSON, 200 обнаруженных инструментов удалённого сервера.
- Схемы конструктора: `type`, `properties`, `required`, `additionalProperties` (boolean), `items`, `enum`, `minimum`, `maximum`, `minLength`, `maxLength`, `minItems`, `maxItems`, `description`, `title`, `default`, `$schema`. Остальные ключи отклоняются явно. Аргументы удалённых инструментов проверяет удалённый сервер.

## Проверка

```sh
node --test tests/mcp.test.cjs
ui-build.cmd --no-increment
```

Ручная проверка: пример → свой инструмент → вызов → экспорт/импорт → подключение к агенту → выполнение из чата; отдельно запустить экспортированный server.mjs и подключиться к нему из библиотеки. Проверять также 640 и 390 px, светлую тему, отмену вызова и ошибки аргументов.

Основание реализации: [MCP transport](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports), [MCP tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools), [официальный TypeScript SDK](https://ts.sdk.modelcontextprotocol.io/server).
