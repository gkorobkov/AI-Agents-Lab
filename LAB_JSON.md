# Редактирование лабораторных в JSON

В текущей Лабе №1 всё относящееся к разделу находится внутри него:

- `objective`: `title` и `blocks`.
- `preparation`: `title` и `blocks`.
- `experiments`: `title`, `description`, подписи полей и статусов в `labels`, задания в `items`.
- `reportInstructions`: `title`, подписи итогового отчёта в `labels`, текстовые блоки в `blocks`.
- `progress`: `type: "progress"` и подписи счётчика, сохранения, скачивания, автора и группы в `labels`.

Общие подписи оглавления и копирования остаются в корневом `labels`. Подписи внутри раздела имеют приоритет. Прежние массивы разделов и корневые подписи продолжают работать для других лабораторных.

Раздел подготовки объединяет заголовок и содержимое: `"preparation": { "title": "Подготовка", "blocks": [...] }`. Редактируйте заголовок прямо в `title`, а порядок элементов — в `blocks`. Старый массив `preparation` поддерживается для совместимости.

Заголовки и подписи интерфейса редактируются в объекте `labels` лабораторной: `objectiveTitle`, `reportTitle`, `experimentsIntro`, `author`, `group`, `results`, `conclusion`, `answerHint`, `reportConclusion`, `reportNote`, `download`, `copy`, подписи сохранения и статусов. В `progress` сохраняйте подстановки `{completed}` и `{total}` для счётчика. `preparationTitle` и `experimentsTitle` задают названия соответствующих разделов. `labels` не отображается отдельным блоком и не влияет на порядок разделов. Пропущенные подписи получают стандартное значение для совместимости со старыми лабораторными.

Содержимое `ui/lab-*.json` отображается в порядке записи в файле:

- Разделы `objective`, `introduction`, `preparation`, `experiments`, `reportInstructions` идут в порядке их ключей в JSON. Переносите раздел целиком, чтобы изменить его место на странице. Оглавление следует тому же порядку.
- Задания внутри `experiments` и блоки внутри `blocks` отображаются в порядке массива, включая вложенные блоки. Вопросы остаются на своих местах.
- `schemaVersion`, `id`, `version` — служебные поля. `title` и `description` задают заголовок и описание. Их порядок также следует JSON.
- `"progress": { "type": "progress" }` — счётчик выполненных заданий, полоска прогресса и кнопка скачивания отчёта. Переносите этот ключ целиком, чтобы переместить панель. По умолчанию поставьте его сразу после `title`. Если ключ отсутствует, панель появится после заголовка для совместимости со старыми файлами. Значение счётчика вычисляется из сохранённых ответов.
- Поля автора и группы следуют за панелью прогресса. Поля ответов добавляются после блоков каждого задания.
- Ссылку можно вынести в отдельный объект верхнего уровня, например `"link": { "type": "link", "text": "Настрой LLM провайдера →", "href": "documentation.html#connect-neuraldeep", "openBeside": "help" }`. Она будет отдельным блоком на месте этого ключа, независимо от `introduction`.

| Блок | Как выглядит |
| --- | --- |
| `type: "paragraph", tone: "normal"` | Обычный абзац с текстом из `text` |
| `type: "paragraph", tone: "muted"` | Приглушённое пояснение |
| `type: "paragraph", tone: "question"` | Выделенный вопрос на том же месте в тексте |
| `type: "list", ordered: true` | Нумерованный список из `items` |
| `type: "list", ordered: false` | Маркированный список из `items` |
| `type: "code"` | Блок кода из `text`, заголовок из `label`, кнопка копирования |
| `type: "details"` | Сворачиваемый блок с заголовком `title` и вложенным массивом `blocks` |
| `type: "link"` | Ссылка с подписью `text` и локальным адресом `href`; `openBeside: "help"` открывает Помощь в соседней панели |

Текст выводится как текст, а не HTML. Для нового абзаца используйте отдельный блок. Не меняйте `id` заданий без необходимости: к ним привязаны сохранённые ответы. Не добавляйте комментарии в JSON.

Для абзаца со ссылками используйте `content` вместо `text`: массив строк и объектов `type: "link"`. Например: `"content": ["Параметр: ", { "type": "link", "text": "temperature: 0.7", "href": "./?page=settings&field=openai-temperature", "openBeside": "settings" }]`. Каждый фрагмент записывается один раз; меняйте значение прямо в подписи ссылки. Элементы массива идут подряд в одном абзаце. У отдельных ссылок `icon: "help"` или `icon: "settings"` добавляет значок страницы без жирного начертания.
