5 Проверка вызова LLM с запросом выбора инструмента

Задача для LLM модели по умолчанию формируется из значений параметров URL с флажком «Заполняет модель». Её можно отредактировать. Модель получит текст задачи и описание инструмента со схемой аргументов. Значения параметров включаются в начальный текст задачи. После нажатия «Вызвать LLM» аргументы из ответа модели появятся в полях параметров URL. HTTP-запрос запускается отдельно кнопкой в разделе 3.
