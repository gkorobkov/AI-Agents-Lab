Новая коллекция использует выбранную размерность и метрику Cosine. Для существующей коллекции выберите ту же модель, которой индексировали документы.

03 · Документ

Метаданные · JSON-объект

Создание проверяет свободный ID. Обновление заменяет текст, вектор и метаданные существующего документа. Перед редактированием прочитайте документ по ID.

04 · Загрузка файлов

Файлы не выбраны.

Каждый файл разбивается на фрагменты с отдельными UUID. Имя файла, номер фрагмента и ID импорта сохраняются в метаданных. Повторная загрузка создаёт новые записи. PDF, DOCX и изображения предварительно сохраните как текст UTF-8.
