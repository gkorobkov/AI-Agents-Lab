Помощь

AI Agents Lab — лаборатория для экспериментов с ИИ-агентами: настраивайте запросы, смотрите Debug и выполняйте лабораторные работы.

Подключение к NeuralDeep

  1. Откройте NeuralDeep и перейдите в личный кабинет. Зарегистрируйтесь или войдите.
  2. Создайте API-ключ в кабинете. Уточните доступные модели и скопируйте точное API-имя выбранной модели из кабинета или списка моделей. Название тарифа может отличаться от API-имени.

Адрес OpenAI-совместимого API: https://api.neuraldeep.ru/v1. Актуальные сведения — в официальной документации.

Настройки в AI Agents Lab

  1. Откройте чат и примите соглашение при первом посещении. В хедере выберите режим OpenAI API, затем нажмите шестерёнку.
  2. Создайте личный профиль кнопкой + или нажмите Clone, чтобы скопировать текущий. Назовите профиль NeuralDeep.
  3. В поле Base URL укажите https://api.neuraldeep.ru/v1. Не добавляйте /chat/completions: приложение добавит его само.
  4. В API key вставьте свой ключ, в Модель — точное API-имя доступной модели. Настройки сохраняются автоматически в этом браузере.
  5. Для первого опыта очистите системный промпт и чат, отключите историю и Tools. Задайте temperature: 0.7, top_p: 1, n: 1, max_completion_tokens: 512.
  6. Введите «Ответь одним словом: привет». Проверьте «Предпросмотр запроса» → «Тело JSON» и отправьте сообщение. Включите Debug кнопкой жука и найдите choices[0].message.content в полном ответе.
Если преподаватель выдал готовый профиль

Выберите Default LLM Provider или указанный преподавателем профиль. Используйте его URL и модель. Для изменения параметров нажмите Clone; настройки защищённого профиля редактировать нельзя. Личный ключ нужен для вашего собственного подключения.

API-ключ сохраняется в браузере. Не включайте его в промпты, отчёты или скриншоты.

Если запрос не проходит

401 / 403 — доступ

Проверьте ключ и права аккаунта на выбранную модель.

Модель не найдена

Сверьте поле «Модель» с точным API-именем из кабинета NeuralDeep.

CORS / Failed to fetch

Прямой запрос из браузера требует поддержки CORS у API. Используйте прокси-профиль, выданный преподавателем, с его URL и моделью.

429 — лимит запросов

Дождитесь завершения текущих запросов и повторите позже. Проверьте лимиты своего аккаунта в кабинете.
