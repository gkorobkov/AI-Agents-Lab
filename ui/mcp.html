MCP / Model Context Protocol

Начните с примера. Соберите инструменты, проверьте вызов и подключите их к агенту.

Один MCP-сервер предоставляет агенту набор инструментов. Клиент узнаёт их через tools/list и вызывает нужный через tools/call.

Первый раз с MCP? Три шага
  1. Оставьте учебный пример или добавьте свои инструменты.
  2. Нажмите «Проверить MCP», выберите инструмент и передайте аргументы.
  3. Подключите инструменты к агенту или скачайте сервер для запуска на Node.js.

01 Ваш сервер

Токен остаётся в этой вкладке и привязан к серверу. Сервер должен разрешать CORS для адреса лаборатории и открывать заголовок Mcp-Session-Id. OAuth и старый HTTP+SSE здесь не поддерживаются.

02 Соберите инструменты

Задайте имя, аргументы и ответ. В шаблоне ответа {{name}} подставляет аргумент name. Для настоящего HTTP-запроса добавьте инструмент из библиотеки.

04 Запустите настоящий сервер

Скачайте файл в отдельную папку. Установите Node.js 20+ и выполните команды в этой папке. Сервер работает на вашем компьютере, пока запущена команда node.

npm install @modelcontextprotocol/sdk@1.30.0
node server.mjs

Затем выберите «Подключить сервер» и адрес http://127.0.0.1:3100/mcp. Разрешённый адрес лаборатории будет включён в скачанный файл. Для HTTP-инструментов с ключом сервер использует переменные окружения MCP_TOOL_KEY_1, MCP_TOOL_KEY_2 и т. д. — по номеру инструмента.
