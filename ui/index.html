How it is built

Previous messages come from OpenAI turns currently visible in this page’s chat. This browser UI adds them to messages[]; this is not a separate OpenAI API parameter.

Messages live only in this page’s DOM while it is open. This UI does not persist them to localStorage or store them on a backend. Only OpenAI messages from the current profile/conversation are included; Webhook and Stub are excluded. They become user/assistant role-content entries. Reload, Clear chat, or New session resets this UI context. With the toggle off, only the optional system prompt and current user message are sent.
